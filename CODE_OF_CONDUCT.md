# Community code of conduct

Signal Engine welcomes thoughtful contributions from people with different backgrounds and experience levels. Be respectful and constructive in code reviews, issues and discussions. Critique technical claims with reproducible evidence and avoid personal attacks, harassment, discriminatory remarks, doxxing or publishing private account details.

Maintainers may close discussions or reject contributions that violate these expectations. Report interpersonal conduct concerns to a repository maintainer using a private contact channel, where one is available. Security vulnerabilities must follow [SECURITY.md](SECURITY.md).

Disagreement about trading assumptions, implementation choices and performance claims is welcome; explain the assumptions and tests behind your position.
